# AI i świat – diagnoza i plan

Esej (PL, ok. 18 min czytania) o tym, jak generatywna AI zmienia gospodarkę i organizacje, oraz uniwersalny plan wdrożenia AI dla firm: od pierwszego demo do wirtualnych pracowników w produkcji. 17 rozdziałów, 64 przypisy ze źródłami.

- `index.html` – jeden samodzielny plik (HTML + CSS + JS), styl edulab; czcionki i ikony (Lucide) z CDN.
- Skróty: `J` / `K` – następny / poprzedni rozdział, `T` – spis treści, `Esc` – zamknij przypis.

Autorzy: Andrzej Jankowski, Agnieszka Karlińska · kwiecień 2026
